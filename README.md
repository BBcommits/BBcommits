### 👋 About me

I find how AI systems fail before a user or an attacker does. My background is software QA (product verification at Ciena), and I now focus on testing and red-teaming LLM applications: prompt injection, system-prompt extraction and multi-turn social engineering.

- 🔭 Building **[threatline](https://github.com/BBcommits/threatline)**, an automated multi-turn prompt-injection test harness for LLM apps
- 📓 Logging red-team practice (Gray Swan Arena, PortSwigger Web Security Academy) in **[redteam-journal](https://github.com/BBcommits/redteam-journal)**
- 🐍 Sharpening Python in **[python-practice](https://github.com/BBcommits/python-practice)**
- 🎯 Working toward CompTIA Security+
